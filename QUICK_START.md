# 🚀 Quick Start - Deploy in 3 Steps

## Step 1: Configure
```bash
cp .env.example .env
nano .env  # Add your values
```

## Step 2: Deploy
```bash
./deploy.sh
```

## Step 3: Configure Bot
```bash
node scripts/configure-bot.js
```

## Done!
Your app is live! Test: Open bot → /start → Start Mining
